Downloading 3 files from COSMIC database (26 jan 2026):
https://cancer.sanger.ac.uk/cosmic/download/cosmic/v103/

- Cosmic_Classification_Tsv_v103_GRCh38.tar
- Cosmic_Sample_Tsv_v103_GRCh38.tar
- TSV

First I filter the tsv according to the samples in the chosen cohort and with the wanted phenotype

I then create mapping coords with mut ID
- NOTE: same coords and same mut --> same mutID

I merge the tables

I count mutations in bins both agnostic and category specific

Coding mutations are associated to an explanation, while noncoding are not

So in the end, a variant can:

- come from different samples
- can have different mutID, with same coords (because different mutation)
- can have same mutID, but different description (ignoring sample provenance and mutation nature)
